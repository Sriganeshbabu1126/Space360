# Space360 Administrator Guide

This guide provides instructions for Space360 administrators on managing projects, users, and permissions.

## 1. Project Creation

To create a new project:
1. Navigate to the **Admin Dashboard**.
2. Click the **Create New Project** button.
3. Enter the project details, including name, description, and client information.
4. Click **Create**. The project will now be available in the system.

## 2. Member & Contractor Management

Administrators can add and manage users within projects:
1. Go to the project settings and select the **Members** tab.
2. To invite a new user, click **Invite Member**.
3. Enter the user's email address and select their role (e.g., Member, Contractor, Viewer).
4. Click **Send Invitation**.
5. You can also edit existing users' roles or remove them from the project using the action menu next to their name.

## 3. Floor Plan Upload

Floor plans are essential for the path overlay feature:
1. In the project workspace, navigate to the **Floor Plans** section.
2. Click **Upload Floor Plan**.
3. Select an image file (e.g., PNG, JPEG) of the floor plan.
4. Once uploaded, you may need to calibrate the floor plan by setting the scale and orientation to ensure accurate path overlays.
5. Save the configuration.

## 4. Permissions & Roles

Space360 utilizes a role-based access control system:
- **Administrator:** Full access to all system settings, user management, and project creation.
- **Project Manager:** Can manage specific assigned projects, including adding members, uploading floor plans, and overseeing issue resolution.
- **Contractor/Member:** Can view assigned projects, upload videos, navigate the 360° viewer, and create/update issues.
- **Viewer:** Read-only access to view projects and videos, but cannot make changes or add issues.

Please assign roles carefully to ensure data security and appropriate access levels for all users.
